# 局域网代理与网络排除

## 让其他设备使用本机代理

1. 保持 FlClash for oixCloud 已启动并有可用配置
2. 在「工具 → 基本配置」开启「局域网代理」，到「端口」查看混合端口
3. 查看本机局域网 IP，在另一设备的代理设置中填写该 IP 与混合端口，选择客户端支持的 HTTP 或 SOCKS 协议
4. 允许可信局域网范围内的防火墙访问，再用目标应用验证并查看连接记录

远端设备不能把 `127.0.0.1` 当成本机的地址。开启共享不会自动接管整个家庭网络，需要在使用代理的设备或应用中设置

### 使用本地代理认证

在「工具 → 基本配置」开启「本地代理认证」，再点「账户 / 密码」查看或修改凭据；另一设备的代理设置也要填写相同凭据。这是本地监听的认证，不是 oixCloud 登录密码

启用认证后，客户端不会自动设置系统 HTTP 代理。需要手动代理的应用必须支持填写用户名与密码；本机是否需要 TUN 应按实际接管场景选择，见 [系统代理与虚拟网卡](/flclash/capture)

只在可信网络开放端口，不要通过路由器端口转发暴露到公网；不同网络隔离或防火墙仍可能阻止其他设备连接

## 连接指定 Wi-Fi 时暂停

入口：「工具 → 进阶配置 → 网络 → 排除SSIDs」

1. 添加准确的 Wi-Fi 名称，连接该网络时暂停代理
2. Android / macOS 若无法识别名称，按界面的定位权限提示授权；无法读取 SSID 时不能依靠名称匹配
3. 离开该 Wi-Fi 后，仅当应用仍处于启动状态时恢复；手动停止应用不会被这个功能自动启动
4. 用加入列表的 Wi-Fi 与未加入的网络各检查一次连接状态，再核对目标应用

同名 Wi-Fi 并不能证明是同一个可信网络，不要把网络名称当作身份认证

## Android：按 IP 或网关暂停代理

当前「按 IP 或网关暂停代理」入口仅在 Android 显示，位于同一网络设置页。它可匹配 Wi-Fi / 以太网的 IPv4、网段或网关，最多 16 条，使用逗号分隔，例如：

```text
192.168.1.0/24,gateway:192.168.1.1
```

填写前换成自己实际网络；这项不接受 IPv6 条件。匹配后暂停转发，离开后按应用运行状态恢复。常用网段会在不同网络重复出现，检查筛选范围，避免误暂停

## 暂停与分流的区别

按网络暂停针对当前网络环境；分流规则针对目标；Android 访问控制针对应用。排查时先确认是否因网络条件暂停，再查看节点、DNS 与规则，避免把预期的暂停当成节点故障
