# 局域网代理与网络排除

## 让其他设备使用本机代理

1. 保持 FlClash 已启动并有可用配置
2. 在网络设置中开启「局域网代理」，核对监听地址及混合端口
3. 查看本机局域网 IP，在另一设备的代理设置中填写该 IP 与端口
4. 允许可信局域网范围内的防火墙访问，再用目标应用验证

远端设备不能把 `127.0.0.1` 当成本机的地址。它还需要支持所配置的代理协议，开启共享不会自动接管整个家庭网络

仅在可信网络开放代理端口，避免通过路由器端口转发暴露到公网。需要本地认证时按界面配置；启用本地代理认证时，不会自动设置系统 HTTP 代理

## 在指定网络暂停代理

「按 IP 或网关暂停代理」可匹配 Wi-Fi / 以太网的 IPv4、网段或网关。例如：

```text
192.168.1.0/24,gateway:192.168.1.1
```

示例仅表示该网段或网关，填写前换成自己实际网络。匹配后暂停转发，离开后恢复；不要把共享地址段误当成唯一的可信网络身份

## 暂停与分流的区别

按网络暂停针对整段网络环境；分流规则针对某个目标；Android 访问控制针对应用。排查时先确认当前是不是已被网络排除规则暂停
