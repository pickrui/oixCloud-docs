# Surge Mac helper

## Connect

1. Install Surge Mac on macOS 12 or later, then download and extract the oixCloud Surge helper from our download center.
2. Double-click 启动 oixCloud.command and choose persistent startup. Click the cloud icon in the menu bar, open Account → Sign in…, and use an Access Token or your email and password.
3. Choose Connection → Apply in Surge, confirm the configuration installation in Surge, then enable Set as System Proxy and select a node in a policy group.

The Surge integration here is an external proxy helper that runs on your Mac alongside Surge. It is not an .sgmodule that can be installed directly on iPhone or iPad; use oixCloud on those devices. After changing the connection mode, use Apply in Surge again. If something goes wrong, start with the helper's Tools → Diagnostics… menu.
