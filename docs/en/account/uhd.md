# UHD benefits

Sign in to the [Benefits Center](https://oixcloud.com/user/benefits#emby) and expand **Emby**. Choose the option that matches whether you already have a UHD account.

## Redeem or link an account {#get-access}

| Goal | What to do in Emby |
| --- | --- |
| Create a new UHD account | Select **Redeem Now**, choose a UHD username and password, check the cost and duration, then select **Confirm Redemption**. Redemption requires an active plan. For regular accounts, the current cost is 5 benefit credits for 365 days |
| Use an existing UHD account | Select **Link an existing UHD account**. Enter your UHD username, password and UHD two-step code if enabled, then select **Verify and link**. Linking is free. The account must be active, in the service’s UHD team and unlinked to anyone else |

After success, the card shows your UHD username and expiry. Use **Open UHD Panel** to continue. See [plan benefit credits](/en/account/benefit-credits) for your credit balance and how credits are earned.

## Extend an existing account {#extend}

1. Before expiry, expand **Emby** and select **Extend Access**. Check the credit cost and extra days, then select **Confirm Extension**.
2. Refresh the card and check the new expiry. Regular accounts need an active plan and sufficient credits. The extension must fit within the maximum validity shown.

UHD accounts are automatically deleted after expiry. Developer accounts redeem for free. They cannot extend before expiry and can redeem again after automatic deletion. If a redemption or extension is still being confirmed, refresh first and follow [UHD troubleshooting](/en/help/support#uhd-redemption-is-still-being-confirmed) before submitting again.
