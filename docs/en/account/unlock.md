# WARP and streaming regions

## WARP and regional streaming access

WARP changes the exit path on supported nodes. With Smart Fallback enabled, traffic connects directly if WARP is unavailable; with it disabled, the connection is rejected. Configure streaming access by supported node, service, and region; unset options follow the node's defaults. These settings do not replace a third-party account or membership, and do not guarantee access to every website. After saving, update the configuration, reconnect, and check the actual result in the target service.
