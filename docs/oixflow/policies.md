# 策略组、自动选择与代理链

适用于 iPhone / iPad，配置可按同步范围发送到 Apple TV

## 选择策略组

1. 在 iPhone 或 iPad 的「主页」点当前节点卡片，展开订阅或文件夹可选单个节点。要切换整组，直接点组名或「自动优选」。卡片会显示新的选择
2. 要新建组，打开「代理 → 策略 → 添加策略组」，填写名称和类型，点「添加成员」，勾选所需节点并保存。回到主页点新组，或把某条[路由规则](/oixflow/routing#website-rule)指向它
3. 在规则模式下，目标为「代理」的请求跟随主页选择。若网站已有指定出口的规则，去那条规则更换目标。若当前网络预设指定了出口，先在[网络预设](/oixflow/networks)中调整，再用新连接验证

| 类型 | 适合的需求 |
| --- | --- |
| 手动 | 使用此设备已选的成员，尚无有效选择时使用首个可用成员 |
| 自动测速 | 依据配置的连接测试选择成员 |
| 故障转移 | 优先使用前面的成员，不可用时切换 |
| 负载均衡 | 将不同连接分配给可用成员 |
| 智能 | 根据实际连接表现学习路线，在建立连接失败时尝试其他成员 |

要固定使用某个组员，可直接在主页的订阅或文件夹中选该节点；只给一个网站使用时，在它的规则中选该节点

主页的「自动优选」是内置自动组；你创建的策略组会作为独立出口供选择。没有可用成员时，先检查成员来源、筛选条件与测试结果

自建组可同时选择独立节点、第三方订阅和托管订阅中的节点，操作见 [创建混合策略组](/oixflow/mixed-nodes#mixed-group)。成员选择器按订阅显示时，「全部」只选中当前节点；来源后续新增的节点不会仅因此自动加入该组。内置「自动优选」的「包含所有代理」则是另一项设置，启用后应留意第三方节点也可能参与优选

## 调整测速与优先级

使用当前网络能访问的测试地址，先保留默认间隔。智能策略的优先级数值越小越优先，1.0 为中性；不要仅因为一次高延迟就把大量成员排除

自动切换通常影响新建连接，正在进行的下载或视频不应被当作切换验证依据。关闭目标应用的旧连接后再复测

### 自动优选的延迟为什么没有刷新 {#retesting}

当前维护版本的内置「自动优选」在后台进行定时检查时，如果上次检查后没有代理流量，会跳过本次重测。设置了间隔不等于空闲时仍不断测速；切网、连接失败或相关配置变化仍可触发检查。不能把此行为直接套用到所有自建策略组或其他客户端

需要立即比较节点时，在「代理 → 服务器」长按节点选择「测试延迟」；批量测试使用工具栏「全部测试」，文件夹也可从自身菜单测试成员。已有结果时，点击延迟数值可查看详情

确认测试完成后，再在主页核对自动优选当前选择，并新建一次目标请求检查出口。手动测得的低延迟不等于一定成为自动优选结果，也不证明目标服务可用；不要把未刷新的数字直接视为连接故障

需要指定入口和最终出口时，按[代理链设置步骤](/oixflow/proxy-chains)配置
