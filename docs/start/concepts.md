| 名称 | 作用 | 举例 |
| --- | --- | --- |
| 系统代理 / VPN / TUN | 让应用流量进入客户端 | FlClash for oixCloud 开启系统代理或虚拟网卡 |
| 分流规则 | 按域名、IP 等条件决定去向 | 公司域名直连，其他请求走代理 |
| 策略组 | 从一组节点中选择出口 | 手选、自动测速、故障转移 |
| 节点 | 实际建立代理连接的服务器 | 选择你有权限使用的节点 |
| 订阅 | 获取和更新当前套餐可用的节点与配置 | 专用客户端登录后自动获取，其他兼容客户端可导入对应格式的订阅地址 |

## 三种模式

| 模式 | 行为 | 使用时注意 |
| --- | --- | --- |
| 规则 | 按规则决定代理、直连或拒绝 | 适合日常使用 |
| 全局 | 主要流量使用所选出口 | 可短暂用于对照排查；本地网络处理仍受客户端设置影响 |
| 直连 | 不通过代理出口访问 | 不用于检验远程节点是否正常 |

在 oixFlow 中，规则的「代理」目标按当前代理选择继续路由；指定节点或策略组则使用指定出口。FlClash for oixCloud 的规则目标必须对应当前配置中存在的节点或组，`PROXY` 可能只是某个配置里的组名，不是通用的“当前代理”关键字，不能直接跨客户端照抄

## 三种凭据不要混用

| 凭据 | 用途 |
| --- | --- |
| Access Token | 填入客户端的 Token 登录框，也可供脚本调用账户接口。完整值只在新增或重新生成时显示一次 |
| 订阅地址 | 在[用户中心 → 订阅地址](/start/quick-start#import-subscription)复制完整网址，粘贴到客户端的订阅栏。「订阅管理」里的「复制 Token」只复制地址中的一段 |
| 节点密码 | 手动添加节点时，填写该节点「配置信息」中的认证参数 |

在网站让一次登录下线，会让共用这份凭据的设备一起退出。需要撤销泄露的订阅地址时，先辨认是个人地址还是主订阅，再按[泄露后的对应处理](/account/security#泄露后的对应处理)操作
