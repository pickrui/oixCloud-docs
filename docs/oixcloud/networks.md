# 网络配置、直连与局域网代理

适用于 iPhone / iPad

## 按网络选择配置

需要在家庭、公司和蜂窝网络使用不同路线时，在「设置 → 网络 → 受信任网络」中添加网络配置，设置匹配条件、模式、出口及规则

1. 先在目标网络创建一份配置并核对匹配条件
2. 选择需要的规则模式与出口，保存后查看当前生效配置
3. 切换到另一网络，确认默认选择恢复
4. 两个网络都检查实际请求，不要只根据配置名称判断是否生效

网络配置可以具有自己的路由选择。修改全局规则后结果不变时，先检查是否有匹配中的网络配置

## 受信任网络与排除路由

「设置 → 网络 → 受信任网络」用于处理指定网络的连接行为；「分流规则 → 排除路由」用于指定目标域名或网段直连，两者不是同一个范围

排除路由优先于普通分流规则。填写公司网段前核对实际地址，避免把一个过大的网段全部绕过隧道

## 提供本地代理服务

在「设置 → 网络 → 代理服务」中按页面说明设置监听地址、端口与访问范围。另一台设备需要手动填写这台设备的局域网地址及相应代理端口

手机必须保持客户端连接、处于可访问的网络，其他设备也必须支持所配置的代理协议。只在可信局域网内使用，不把监听端口转发到公网

## 高级网络开关

IPv6、增强兼容模式与 Apple 推送接管解决不同问题。先保留默认值，只针对已确认的需求逐项调整；涉及包含所有网络或按需连接时，先阅读应用中的说明
