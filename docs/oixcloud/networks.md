# 网络预设、直连与局域网代理

适用于 iPhone / iPad

打开「设置」，在「网络」分区选择「网络预设」；「网络」是分区标题，无需先进入一个同名页面

1. 添加当前 Wi-Fi、手动填写准确的 Wi-Fi 名称（SSID），或添加蜂窝网络预设
2. 按需要设置模式、兜底路由、路由规则、DNS 与 IPv6；「继承」使用全局设置
3. 保存并连接，在该网络下检查当前生效预设与实际请求
4. 切换到没有对应预设的网络，核对全局设置重新生效

选择「直连模式」会让流量直连；只把「兜底路由」设为直连时，匹配到规则的请求仍可走代理。需要连接到该网络时自动启动 VPN，可开启预设里的「自动连接」；全局「始终开启」优先于此选项

预设可以使用自己的路由规则。修改全局规则后结果不变时，先查看当前预设是否选择了自定义规则

## 网络预设与排除路由

网络预设按当前 Wi-Fi 或蜂窝环境选择设置；「代理 → 策略 → 路由规则 → 排除路由」按目标域名或网段指定直连，两者作用范围不同

排除路由优先于普通路由规则。填写公司网段前核对实际地址，避免把过大的网段全部绕过隧道

## 提供本地代理服务

在「设置」的「网络」分区打开「代理服务」，按页面说明设置端口与访问范围。另一台设备填写这台设备的局域网地址及相应代理端口

手机必须保持客户端连接、处于可访问的网络，另一台设备也必须支持所配置的代理协议。只在可信局域网内使用，不把监听端口转发到公网

## 高级网络开关

IPv6、增强兼容模式与 Apple 推送接管解决不同问题。先保留默认值，只针对已确认的需求逐项调整；涉及包含所有网络或按需连接时，先阅读应用中的说明
