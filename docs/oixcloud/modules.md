# 模块导入、参数与排序

适用于 iPhone / iPad。Apple TV 不接收模块

模块可以组合分流、DNS、重写和脚本。仅有普通节点连接需求时，无需开启模块

1. 在「代理 → 策略」中进入「模块」，选择「导入模块」或「订阅模块」
2. 选择文件或粘贴作者提供的资源地址
3. 按资源实际格式选择客户端类型，核对名称、规则、脚本和不支持项目的提示
4. 需要参数的模块先编辑参数，再按用途启用相应内容
5. 打开目标服务，核对效果；有 HTTPS 重写时继续完成 [MITM 证书与信任](/oixcloud/mitm)

界面的格式建议只用于辅助选择。模块可导入，并不保证作者在其他客户端使用的全部 API 都受支持

## 更新、分类与参数

从模块操作菜单更新订阅或修改参数。分类用于整理列表；运行优先级使用「生效顺序」调整，不要依靠分类名称控制先后

更新后重新查看警告和未生效内容，尤其是脚本、DNS 与目标主机变化。某项不受支持时，应按具体提示处理

## 多个模块冲突

模块按配置顺序处理。多个模块提供 DNS 覆写时，优先模块占用该设置；多个模块匹配同一主机时，脚本也受顺序影响

先只启用一个相关模块确认效果，再逐个加入其他模块。调整顺序后重新建立连接，检查请求与模块提示

## 停用与移除

先停用模块做对照排查。删除会移除它贡献的规则、脚本和 MITM 主机；仍然异常时检查其他模块以及手动添加的规则

脚本可读取匹配的请求和响应，并主动发起网络请求。使用可信来源，不要把带有账户信息的脚本参数分享到公开页面

## 把一次导入验收完整

导入前先确定模块解决哪个具体问题，并保存原有设置。导入后依次查看解析提示、启用状态、参数值以及需要的 MITM 主机；只出现模块名称还不能证明脚本已运行

先手动访问一个模块应处理的目标，在活动记录和模块提示中检查结果。失败时先停用其他可能影响同一目标的模块，再核对资源格式、脚本兼容性和证书信任；不需要 HTTPS 重写的模块不必为了导入而生成证书

订阅更新可能改变作者的规则、主机和脚本。更新后重复验证同一目标，确认没有覆盖仍需保留的本地参数；文件导入的内容不会因为作者更新远程文件就自动变成新版本
