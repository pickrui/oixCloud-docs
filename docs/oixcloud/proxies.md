## 添加自有节点或订阅

1. 打开「代理」，点添加入口
2. 选择链接、文件或二维码导入，使用提供方给出的完整地址
3. 核对导入预览中的节点、策略组或规则，处理不支持的条目后确认
4. 回到主页选择新节点，连接并访问目标网站

单节点分享链接与整份订阅不同。导入 Surge 配置时，预览会列出可识别的内容；不要把“导入成功”等同于原客户端全部功能完全兼容

### 一键导入链接 {#add-proxy-link}

支持此功能的版本可打开 `oixcloud://add-proxy?link=…` 或 `anywhere://add-proxy?link=…` 链接；2.1.6（520）起也可在添加代理页粘贴、扫描或输入完整的一键导入链接。这里的省略号仅示意格式，不可直接用于导入

按导入页核对其中携带的是单节点还是订阅，再确认保存，回到列表检查新增条目。链接可能包含节点凭据或订阅密钥，不要交给公开转换网站。没有对应入口或无法识别时，确认安装版本，或使用提供方给出的原始节点／订阅链接

## 用文件夹整理独立节点 {#folders}

以下文件夹操作适用于 iPhone / iPad 的 2.1.6（520）及后续支持版本；是否可下载以所用发布渠道为准。本页节点选择示意图不展示文件夹编辑，Apple TV 不据此视为具有相同管理界面

1. 在「代理」选择「服务器」区域，从工具栏的更多操作中点「新建文件夹」
2. 填写名称，点「添加代理」选择未归入其他文件夹的独立节点，完成选择后保存
3. 长按节点，在操作菜单选「移到文件夹」；已归类节点可「移出文件夹」，也可移到其他文件夹
4. 长按文件夹选「编辑」，可修改名称、添加成员及拖动成员排序；文件夹之间的顺序通过「重新排序代理」调整
5. 展开文件夹确认节点和顺序，再回主页检查当前出口；整理文件夹本身不会切换连接

文件夹只整理独立节点，不收纳订阅中的节点，也不是策略组或代理链。同一个节点只在一个文件夹中显示

::: info 删除文件夹与删除节点不同
**删除文件夹不会删除其中节点**，节点会回到未归类列表；编辑时移除成员也只是移出文件夹。直接删除节点是另一项操作，应先检查规则引用。文件夹随「代理」类别进行 iCloud 同步，兼容条件见 [同步与版本](/oixcloud/sync#folder-sync)
:::

在订阅的操作菜单中使用「更新」。托管 oixCloud 节点使用账户页的「刷新节点」，账户信息下拉刷新并不等于重新获取节点

在「oixCloud → 节点筛选」按线路、地区和名称设置条件，查看预览后保存，客户端会重新获取托管节点。恢复默认会回到智能优选；筛选不会增加套餐权限，同一账户的同款客户端会共享设置，详见 [订阅与筛选](/account/subscriptions)

## 测试延迟

可测试单个节点或批量测试，再查看延迟详情。一次连接测试不能代表持续带宽，也不能证明指定流媒体可用；只比较同一网络、相近时间下的结果

## 删除与恢复

删除节点或订阅前确认是否被策略组、代理链或规则引用。「最近删除」可恢复本机三天内删除的节点与订阅，不是跨设备回收站；超过期限不能从这里恢复

恢复后核对当前选择和关联规则，再实际连接验证
