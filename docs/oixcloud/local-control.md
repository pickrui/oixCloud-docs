# 局域网控制

适用于提供「设置 → 局域网控制」的 iPhone / iPad 版本。它让同一 Wi-Fi 或以太网内的设备管理这台设备上的 oixCloud，与 [让其他设备使用代理](/oixcloud/networks) 是不同功能

## 开启并连接

1. 在 oixCloud 建立连接，进入「设置 → 局域网控制」，开启「允许局域网访问」
2. 默认端口为 `9091`。如需更换，选择未占用的 `1024–65535` 端口，不能与 HTTP / SOCKS5 代理服务共用，点「应用」
3. 确认状态为可用，复制页面列出的 HTTPS 局域网地址，在同一网络的另一台设备上打开
4. 浏览器显示证书提示时，先核对其证书指纹与应用中的「证书指纹」一致，再继续；不一致就停止连接并核对地址
5. 在应用中「复制访问密钥」，填入控制台连接。使用的是此设备的局域网密钥，不是账户 Access Token 或登录密码

控制服务只在连接已建立时可用，蜂窝网络和热点不能据此推断可访问。切换网络后地址可能改变，重新从应用复制

## 可以做什么

- 查看当前节点、模式、传输量、速率和活动连接数量
- 搜索、分页选择可用节点；确认切换后检查实际结果，现有连接可能重建
- 展开近期日志排查问题；控制台只显示近期有限条目，不能代替完整诊断记录

页面可见时定期刷新。如果当前网络预设控制节点，先在应用里调整该预设；提示其他位置已变更选择时刷新后重试，不要连续覆盖

## 结束访问或更换密钥

浏览器中的「锁定」清除该页的登录状态。需要让现有控制端全部失效时，在应用点「重置访问密钥」，之后各控制端必须输入新密钥；它不修改账户 Token

不用时关闭「允许局域网访问」。访问密钥只在控制台当前页面内存中使用，不要分享密钥、证书私钥或包含敏感内容的日志

| 现象 | 检查方向 |
| --- | --- |
| 没有局域网地址 | 连接 Wi-Fi，确认系统局域网权限与网络可用性 |
| 状态不可用或连接失败 | 连接是否已建立、设备是否已解锁、端口是否冲突、Wi-Fi 是否隔离客户端 |
| 密钥无效 | 重新从当前设备复制；重置后旧密钥失效 |
| 不能切换节点 | 当前网络预设是否指定节点，或节点列表是否已变化 |

这个控制台不能在连接关闭时远程替你建立连接，也不是公开的互联网管理入口
