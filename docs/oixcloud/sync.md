# iCloud 同步与最近删除

适用于 iPhone / iPad，电视同步使用独立开关

::: tip 先统一版本
参与同步的设备使用 oixCloud 1.34 或更新版本。1.33 及更早版本采用不同同步机制，不应混用来验证同步
:::

## 开启同步

1. 在各设备使用同一 Apple 账户，确认 iCloud 可用
2. 进入「设置 → iCloud 同步」，开启需要的类别
3. 使用「立即同步」，等待状态完成后在另一台设备检查
4. 先新增一条易识别的普通配置验证，再整理大量规则或节点

可选类别包括代理、规则、模块、MITM、自动化、设置与账户。关闭某一类别会停止这部分传输，不会自动清空它的本地内容

## 账户变更与恢复提示

Apple 账户变化或云端数据被删除后，应用会要求选择如何处理。上传并合并会把本机内容加入云端；使用 iCloud 数据会用云端替换所选同步范围内的本机内容，云端为空的类别也会变为空

先在保留完整数据的设备上确认内容，再选择操作。不要在所有设备上连续执行删除云端数据来排查同步

## 最近删除

「代理 → 最近删除」保留本机三天内删除的节点和订阅。它不随 iCloud 同步，恢复时也不会自动恢复之前的连接选择

## 同步到 Apple TV

开启「同步到 Apple TV」后，还需在电视端开启 iCloud 同步。它传递节点、订阅、代理链、策略组、规则集和账户状态，电视保留自己的连接与路由设置，不接收模块

详见 [Apple TV](/oixcloud/apple-tv)
