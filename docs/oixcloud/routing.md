## 给网站指定出口

1. 保持「规则」模式，进入「代理 → 策略 → 路由规则」
2. 添加自定义规则，选择域名匹配类型，例如「域名尾缀」并填写 `example.com`
3. 选择直连、拒绝、当前代理，或指定节点、代理链、策略组
4. 保存后重新打开目标网站，在请求详情中核对命中的规则和实际出口

只填域名，不要把 `https://` 或网页路径填进域名后缀字段。后缀规则用于网站及其子域名，精确域名只用于该主机名

## 规则没有生效时看哪里

- **排除路由**最先处理，命中的地址会直连或绕过隧道
- 在「分流指南」中查看来源优先级，支持拖动调整；页面上分类的显示顺序不等于匹配顺序
- 「列表顺序」从上到下检查，先匹配的规则或规则集生效
- 「最具体匹配」在同一来源的规则集中比较具体程度；独立自定义规则仍按列表顺序
- 都没匹配时，使用「兜底路由」

全局与直连模式不会按普通分流规则工作，排查前先确认当前模式

## 导入规则集

在分流规则中从文件导入或通过 URL 订阅支持的 `.arrs`、`.list`、`.conf` 等格式。先查看预览，导入后为规则集指定去向

规则文件描述匹配对象，规则集的去向由你在客户端选择。更新订阅通常保留本地选择，不需要直接修改每个域名条目

## 修改内置规则

点内置规则集名称可查看、搜索并编辑内容，右侧去向入口用于选择路由。「恢复默认」会丢弃该规则集的本地内容修改；清空内容与恢复默认不同

GeoIP / ASN 规则需要对应数据库；HTTPS 路径与请求头规则需要可读取的 HTTP 信息，涉及 HTTPS 内容时还依赖 [MITM](/oixcloud/mitm)
