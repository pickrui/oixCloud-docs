# 提交有效的服务单

## 先准备这些信息

服务单请写明：设备与系统版本、客户端名称与版本、发生时间、所用网络、节点名称、具体操作、完整报错及已尝试的步骤。只附脱敏后的截图和日志；账户、套餐和节点问题可通过本站服务单联系，Surge 或 OpenClash 自身的软件问题也可向相应开发者反馈

## 限速、积分或账户限制 {#restrictions}

先按 [公平使用](/account/fair-use) 和 [流量限制对照表](/account/traffic#limits) 检查原因。提交服务单时补充：

- 限制提示或通知原文、发生时间与时区
- 当前套餐、有效期、剩余流量及积分变化；按量套餐同时说明余额状态
- 对应时段的活动请求、Working nodes、节点名称，以及当时运行的应用或任务
- 已停止哪些异常活动，后续积分与限制是否变化

只提供脱敏记录，不发送密码、完整订阅或 Access Token。封禁的具体判定和检测细节不公开，也不承诺自动解除；提交实际情况供支持核查即可

## 套餐售罄 {#stock}

先阅读 [售罄与自动补货](/account/plans#stock)。限量套餐通常不手动补货，没有固定补货时间；停止续费要等符合条件的到期释放，单纯切换套餐不会立即回补。无需反复提交催补货的服务单

若已付款但套餐没有生效，请另行提供订单号、付款时间、充值记录和套餐管理中的状态；不要把支付到账等同于已占到套餐库存，也不要重复付款

## 付款未到账或套餐未生效 {#payment}

先分别检查充值记录与套餐管理；虚拟币订单可按 [未到账反馈步骤](/account/plans#crypto-payment-feedback) 使用原订单入口

服务单提供原订单号、付款时间与时区、支付方式、实际金额、充值记录和套餐状态，以及反馈结果原文。虚拟币付款补充所用链路和交易哈希；只在私人服务单内提供必要资料，不发送钱包私钥、助记词、登录密码或验证码

说明你希望核查的是「付款是否到账」还是「到账后套餐购买／激活未完成」。若显示正在查询或人工审核，保留原记录等待结果；入口过期或不存在时说明这一情况，不要重复付款

## UHD 兑换显示正在确认

在 [权益中心](https://oixcloud.com/user/benefits) 点击 UHD 的刷新按钮核对状态，等待期间不要重复兑换

- 提示创建结果无法确认、额度暂扣时，等待至少 10 分钟后再刷新；系统成功查询并确认没有创建本人账户后，才退回暂扣的权益额度
- 查询失败时会继续保留待确认状态；提示创建成功但仍在同步资料，也不能仅因等待超过 10 分钟就判断应当退款
- 页面确认额度已退回后，可重新兑换；持续无法确认时，提交兑换时间、页面提示和额度变化，隐藏 UHD 密码及其他凭据

额度返还是权益额度，不是账户余额或原路退款

## 可直接填写的模板

```text
设备与系统：
客户端与版本：
发生时间和时区：
网络环境（Wi-Fi / 蜂窝 / 有线）：
节点名称：
具体操作和目标服务：
完整报错：
已尝试的步骤与结果：
```

不要把密码、完整订阅链接、Access Token、节点凭据或证书私钥粘贴到公开 GitHub Issue。账户问题请使用 [网站服务单](https://oixcloud.com/user/ticket)

若问题来自某个模块，补充模块名称、来源与启停对照结果，不要公开包含个人数据的请求正文
