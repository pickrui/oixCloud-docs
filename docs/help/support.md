# 提交有效的服务单

## 先准备这些信息

服务单请写明：设备与系统版本、客户端名称与版本、发生时间、所用网络、节点名称、具体操作、完整报错及已尝试的步骤。只附脱敏后的截图和日志；账户、套餐和节点问题可通过本站服务单联系，Surge 或 OpenClash 自身的软件问题也可向相应开发者反馈

## 可直接填写的模板

```text
设备与系统：
客户端与版本：
发生时间和时区：
网络环境（Wi-Fi / 蜂窝 / 有线）：
节点名称：
具体操作和目标服务：
完整报错：
已尝试的步骤与结果：
```

不要把密码、完整订阅链接、Access Token、节点凭据或证书私钥粘贴到公开 GitHub Issue。账户问题请使用 [网站服务单](https://oixcloud.com/user/ticket)

若问题来自某个模块，补充模块名称、来源与启停对照结果，不要公开包含个人数据的请求正文
