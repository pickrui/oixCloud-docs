# 中继与自建落地

## 中继和自建落地有什么区别？

内部中继通过一个入口转发到目标节点；外部中继将流量转发至你指定的目标。协议保持模式需要按页面指令部署落地服务器，协议转换模式可转发到已有的 SSH、远程桌面或游戏等服务。先确认来源、目标、模式和端口，保存后更新客户端配置；外部中继不用于转发 Web 网站或网页管理面板，代理串联需求优先使用客户端的链式代理

::: warning 切换前保留配置
同一个逻辑节点的 WARP、中继和自定义中继可能互相排斥；开启 WARP 会清理相关的中继设置，切换前请保存所需配置
:::
