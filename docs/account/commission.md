# 佣金转余额与提现

打开[推介计划](https://oixcloud.com/user/invite)，点「提现或转入余额」，也可直接打开[申请提现](https://oixcloud.com/user/ticket/referral_program)。先看可用佣金，再填写要使用的**人民币金额**

## 转至账户余额 {#balance}

**转入后只能用于账户消费，无法再提现**。最低转入 ¥0.01，免手续费。在「转至余额」点「确认转入」，核对金额并按提示用 Passkey 或当前密码验证。完成后核对账户余额与剩余佣金

## 提取 USDT {#withdraw}

1. 确认有有效套餐，输入至少 ¥200 的提取金额。选择已开放的 **TRC-20** 或 **Polygon**，填入同一网络的 USDT 收款地址，点「提交申请」
2. 确认前核对网络、完整收款地址、手续费和实际到账金额。目前 TRC-20 手续费为 ¥20，Polygon 为 ¥0。账户有欠费时，先用佣金抵扣欠费，余下的佣金才可提现；确认框会列出抵扣额和佣金总扣减额
3. 核对无误后用 Passkey 或当前密码验证。在同页「提现记录」查看处理状态、USDT 金额和交易哈希。结果不明时先查记录，再决定是否重试
