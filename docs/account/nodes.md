# 节点与连接方式

## 怎样选择节点？

先按需要的地区与账户可见节点选择，再参考延迟和实际访问效果。延迟低不等于下载快，也不保证流媒体解锁；同一地区的不同入口、出口和线路可能有不同表现

## 各类节点介绍 {#node-types}

以下介绍参考 [官网首页](https://oixcloud.com/#network)。线路、速率、流量及功能按套餐与节点提供，选择前请查看当前套餐、[节点列表](https://oixcloud.com/user/node) 和客户端要求

| 节点类型 | 网络特点与定位 |
| --- | --- |
| <span id="edge"></span>**Edge**<br>全球网络 | 以 Tier 1 骨干网络与上游互联提供全球接入，适合不需要中国大陆专项路由优化的访问需求 |
| <span id="cia"></span>**CIA**<br>中国优化网络 | 在国际骨干网络上加入 CMIN2 或同等级资源，为中国大陆方向提供尽力而为的路由优化 |
| <span id="ixp"></span>**IXP**<br>云网互联 | 通过互联网交换中心连接云服务商与内容网络，面向支持的云网络接入，减少公网绕行 |
| <span id="fusion"></span>**Fusion**<br>专网互联 | 以香港为国际枢纽，经广港专线接入，再由香港连接全球节点 |
| <span id="fusion-advanced"></span>**Fusion Advanced**<br>专网互联 | 提供更高调度优先级与链路冗余，并增加沪日专线，面向多设备与持续传输需求 |
| <span id="fusion-premium"></span>**Fusion Premium**<br>专网互联 | 提供最高等级调度优先级与多重冗余，面向更重视延迟、抖动与持续可用性的需求 |
| <span id="gia"></span>**GIA**<br>旗舰中国优化 | 整合 Tier 1 骨干网络与包括 CN2 GIA 在内的 Premium Transit 资源，面向需要更高等级中国优化路由的访问需求 |

### 专线接入对照 {#dedicated-lines}

| 节点类型 | 广港专线 | 沪日专线 |
| --- | --- | --- |
| IXP | 华南互联网交换点 → 香港 | 华东互联网交换点 → 日本 |
| Fusion | 华南接入点 → 香港 | — |
| Fusion Advanced | 华南接入点 → 香港 | 华东接入点 → 日本 |
| Fusion Premium | 华南接入点 → 香港 | 华东接入点 → 日本 |

IXP 为云网专线接入，Fusion 系列为专线接入；「—」表示首页未列出该接入方向

## 规则、全局与直连

| 模式 | 流量去向 |
| --- | --- |
| 规则 | 按目标匹配分流策略 |
| 全局 | 将被客户端接管的流量交给所选代理 |
| 直连 | 不通过代理节点 |

::: info 全局模式与流量接管是两件事
全局模式不代表系统中的每个应用都已被接管，仍取决于 VPN、TUN 或系统代理是否生效
:::

## 协议、端口与高级选项

优先使用客户端生成的托管配置，避免照抄旧教程中的端口或协议组合。只有节点和客户端都支持的选项才有效；不确定时保留默认值，修改后刷新配置并验证实际连接

## 购买与续费独享 IP

| 核对项 | 要求 |
| --- | --- |
| 套餐资格 | 须有当前有效套餐；仅有待激活套餐时需先激活 |
| 独享 IP 到期时间 | 新到期时间不得晚于套餐预计到期时间，以购买窗口显示的「独享 IP 最晚到期」为准 |
| 套餐预计到期时间 | 当前套餐到期时间，加上按队列可连续激活套餐的剩余时长 |
| 购买与手动续费月数 | 单次最多 12 个月；新购还须满足商品显示的最低月数，手动续费可选 1 个月起 |
| 计费月 | 每月固定 30 天 |

Edge 级别节点面向国际网络环境，从部分地区（如中国大陆）接入时，不提供 SLA 保障

### 自动续费 {#ip-auto-renewal}

| 项目 | 规则 |
| --- | --- |
| 尝试时间 | IP 到期前 24 小时内 |
| 每次续期 | 延长 30 天，系统不会自动增加扣款月数 |
| 扣款条件 | 有当前有效套餐、足够的可用余额（含佣金），且新 IP 到期时间不晚于套餐预计到期时间（含有效待激活套餐） |
| 条件不符 | 保留开关、暂停扣款，到期前继续尝试 |

::: warning 到期前确认续费结果
若延长 30 天会超过套餐预计到期时间，须先延长套餐有效期，再核对续费资格；增加 IP 续费月数不能解决此问题。到期仍未续费的 IP 将被回收
:::

## 第一次选节点的步骤

1. 在 [节点列表](https://oixcloud.com/user/node) 核对账户可用节点、地区、线路和倍率
2. 更新客户端的托管配置；节点不在列表时先查 [筛选条件](/account/subscriptions)，不要把没有显示直接当成故障
3. 选择一条符合用途的节点，先测试同一个目标网站或应用
4. 延迟正常但业务失败时，在连接记录确认流量确实经它出站，再换同地区另一节点作对照

需要特定流媒体地区时查看 [流媒体设置](/account/unlock)；需要自动切换时使用客户端的策略组。每次只改一个变量，便于区分本地接管、路由、节点和目标服务的问题

## 独享 IP 购买后的检查

1. 在购买窗口核对节点、计费月数、最晚到期要求、最低购买月数和金额，再确认
2. 完成后核对已分配的地址和到期时间；不要只凭支付成功页面认定客户端已经更新
3. 检查官方客户端筛选预览是否保留该节点，再更新配置并建立新连接
4. 用自己的业务核对实际出口；需要续费时预留时间处理余额和套餐资格

独享 IP 的使用期限须由当前有效套餐及可连续激活的待激活套餐覆盖。套餐期限不足时，先延长套餐，或在商品最低购买月数范围内减少 IP 购买月数；以购买／续费窗口的最晚到期提示为准

## 支持节点的独立 IPv6 {#dedicated-ipv6}

在 [WARP 设置](https://oixcloud.com/user/warp) 或 [流媒体解锁](https://oixcloud.com/user/unlock) 页查看「独立 IPv6」及支持节点列表，按需开启。仅列出的支持节点会使用为账户分配的独立 IPv6 出口，其他节点不受影响；没有可用支持节点时不显示此设置

保存后等待节点同步，以新连接验证目标服务看到的出口。这里控制服务端节点的出口，与本机是否接管 IPv6、是否请求 AAAA 记录及连接节点使用的地址族不同，不能用客户端的一个 IPv6 开关代替核对

## 查看服务状态 {#service-status}

登录后打开 [服务状态](https://oixcloud.com/status)，按当前账户可见的节点范围查看状态与更新时间。页面会自动刷新，刷新失败时会提示并稍后重试；节点状态不等于从你当前网络到目标服务的连接测试

若状态正常但仍无法访问，在客户端更新配置后用同一目标做对照，并按 [故障排查](/help/troubleshooting) 提交节点名称、时间与具体错误
