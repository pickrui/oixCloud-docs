# 节点与连接方式

## 怎样选择节点？

先按需要的地区与账户可见节点选择，再参考延迟和实际访问效果。延迟低不等于下载快，也不保证流媒体解锁；同一地区的不同入口、出口和线路可能有不同表现

## 规则、全局与直连

规则模式按目标匹配分流策略；全局模式将被客户端接管的流量交给所选代理；直连模式不通过代理节点。全局模式不代表系统中的每个应用都已被接管，仍取决于 VPN、TUN 或系统代理是否生效

## 协议、端口与高级选项

优先使用客户端生成的托管配置，避免照抄旧教程中的端口或协议组合。只有节点和客户端都支持的选项才有效；不确定时保留默认值，修改后刷新配置并验证实际连接

## 购买与续费独享 IP

购买或续费独享 IP 须有当前有效套餐，仅有待激活套餐时需先激活。独享 IP 的新到期时间不得早于套餐预计到期时间，预计到期时间为当前套餐到期时间加上按队列可连续激活套餐的剩余时长；以购买窗口显示的最早到期时间为准，每个计费月固定 30 天

Edge 级别节点面向国际网络环境，从部分地区（如中国大陆）接入时，不提供 SLA 保障

自动续费在 IP 到期前 24 小时内尝试延长 30 天，须有当前有效套餐、足够的可用余额（含佣金），且续费后的 IP 到期时间不得早于套餐预计到期时间（含有效待激活套餐）。若延长 30 天仍不够，请手动选择更多续费月数；系统不会自动增加扣款月数，条件不符时保留开关并暂停扣款，到期前继续尝试，到期仍未续费的 IP 将被回收
