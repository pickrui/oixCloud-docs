# 节点与连接方式

## 怎样选择节点？

先按需要的地区与账户可见节点选择，再参考延迟和实际访问效果。延迟低不等于下载快，也不保证流媒体解锁；同一地区的不同入口、出口和线路可能有不同表现

## 各类节点介绍 {#node-types}

以下介绍参考 [官网首页](https://oixcloud.com/#network)。线路、速率、流量及功能按套餐与节点提供，选择前请查看当前套餐、[节点列表](https://oixcloud.com/user/node) 和客户端要求

| 节点类型 | 网络特点与定位 |
| --- | --- |
| <span id="edge"></span>**Edge**<br>全球网络 | 以 Tier 1 骨干网络与上游互联提供全球接入，适合不需要中国大陆专项路由优化的访问需求。面向国际网络环境，从部分地区（如中国大陆）接入时，无法保证连接的可用性与稳定性，可尝试启用 [AnyTLS with CDN](https://oixcloud.com/user/anytls) 功能，以改善连接表现，实际效果取决于当地网络环境 |
| <span id="isp"></span>**[Home ISP](#home-isp)**<br>家庭宽带 | 家庭宽带落地，分为静态 IP 与动态 IP。面向国际网络环境，不作任何承诺，不提供 SLA 保障 |
| <span id="cia"></span>**CIA**<br>基础优化网络 | 在国际骨干网络上加入 CMIN2 或同等级资源，为中国大陆方向提供尽力而为的路由优化 |
| **[IXP](#ixp)**<br>云网互联 | 通过互联网交换中心连接云服务商与内容网络，依托优质云网专线，减少公网绕行 |
| <span id="fusion"></span>**Fusion**<br>专网互联 | 以香港为国际枢纽，经广港专线接入，再由香港连接全球节点 |
| <span id="fusion-advanced"></span>**Fusion Advanced**<br>专网互联 | 提供更高调度优先级与链路冗余，并增加沪日专线，面向多设备与持续传输需求 |
| <span id="fusion-premium"></span>**Fusion Premium**<br>专网互联 | 提供最高等级调度优先级与多重冗余，面向更重视延迟、抖动与持续可用性的需求 |
| <span id="gia"></span>**GIA**<br>旗舰优化网络 | 整合 Tier 1 骨干网络与包括 CN2 GIA 在内的 Premium Transit 资源，面向需要更高等级中国优化路由的访问需求 |

### 专线接入对照 {#dedicated-lines}

| 节点类型 | 广港专线 | 沪日专线 |
| --- | --- | --- |
| IXP | 华南互联网交换点 → 香港 | 华东互联网交换点 → 日本 |
| Fusion | 华南接入点 → 香港 | — |
| Fusion Advanced | 华南接入点 → 香港 | 华东接入点 → 日本 |
| Fusion Premium | 华南接入点 → 香港 | 华东接入点 → 日本 |

IXP 为云网专线接入，Fusion 系列为专线接入；「—」表示首页未列出该接入方向

## Home ISP 家宽节点 {#home-isp}

Home ISP 与 Edge 同级，按相同套餐权限开放，但在节点列表中单独展示。选择前核对账户当前可见节点与实际出口

| 列表分类 | 含义 |
| --- | --- |
| Home ISP · 静态 IP | 通常使用固定的落地 IP，实际地址以节点当前出口为准 |
| Home ISP · 动态 IP | 落地 IP 可能变化，不适合依赖长期固定地址的用途 |

静态／动态描述的是节点的落地 IP 类型，不代表为账户分配独享 IP；两类均不承诺可用性或流媒体解锁效果

### 默认订阅与主动选择 {#isp-subscription}

是否默认下发由服务方逐节点设置，与静态／动态分类无关。未开启默认下发的 Home ISP 不会自动进入普通订阅或智能优选，也不会在默认节点为空时被自动补入。含 CIA、IXP、Fusion 或 GIA 的套餐，智能优选只下发套餐的默认线路，开启默认下发的 Home ISP 也不包含

需要使用时，在 [订阅管理](https://oixcloud.com/user/sub_manage) 编辑当前地址，或打开支持的客户端「节点筛选」，将线路 **ISP** 设为「仅保留」，核对预览后保存并更新订阅。ISP 筛选同时包含有权限的静态与动态家宽节点，不会同时选中 Edge；仅筛选地区或名称不会加入未默认下发的 ISP。具体入口与功能资格见 [订阅与筛选](/account/subscriptions#home-isp)

### 流量路由限制 {#isp-routing}

未开启默认下发的 Home ISP 可以作为内部中继的目标／出口节点，但不能作为入口或中间节点；外部中继、HTTP/3、CDN、WARP、IPv4 Only 和流媒体解锁仍不可配置。手动把 ISP 加入订阅不会解除这些限制，「所有节点」这类通配来源也不能绕过限制

管理员手动禁用的节点仍不能作为中继入口或出口；同名节点按整组判定配置资格。已有配置继续生效并可删除；所有节点仍须满足套餐权限、功能支持与页面显示的配置条件。具体中继与客户端代理链设置见 [Home ISP 使用指南](/account/home-isp)

## IXP 云网互联节点 {#ixp}

IXP 通过互联网交换中心连接云服务商与内容网络，使用云网专线接入；方向对照见 [专线接入表](#dedicated-lines)。实际延迟和吞吐取决于本地网络、入口与所选节点，应在相同条件下测试，不把某个地区的示例延迟当作保证

### 套餐权限与接入特性 {#ixp-access}

Pass Alu、Pass Bronze 及更高等级套餐通常包含 IXP，仍以当前账户权限和节点列表为准。使用 [软件中心](https://oixcloud.com/client) 提供的兼容客户端和对应托管配置，不要把节点地址或端口照搬到不支持的普通配置中

普通订阅是否包含节点还受格式、默认下发和筛选条件影响；智能优选按套餐选择默认线路，不代表包含所有可用节点。具体规则统一见 [订阅与筛选](/account/subscriptions)

### 接入机制与网络要求 {#ixp-connectivity}

先更新托管配置，在客户端选择可见的 IXP 节点，再用目标网站验证。不能连接时记录客户端版本、节点、网络与时间，检查订阅同步和客户端接管后再对照其他节点

动态地址处理由兼容客户端和托管配置完成，不需要为了普通连接自行购买云主机。延迟、下载速度与目标服务可用性应分别判断，详见 [连接与速度排查](/help/troubleshooting)

## 规则、全局与直连

| 模式 | 流量去向 |
| --- | --- |
| 规则 | 按目标匹配分流策略 |
| 全局 | 将被客户端接管的流量交给所选代理 |
| 直连 | 不通过代理节点 |

::: info 全局模式与流量接管是两件事
全局模式不代表系统中的每个应用都已被接管，仍取决于 VPN、TUN 或系统代理是否生效
:::

## 协议、端口与高级选项

优先使用客户端生成的托管配置，避免照抄旧教程中的端口或协议组合。只有节点和客户端都支持的选项才有效；不确定时保留默认值，修改后刷新配置并验证实际连接

需要调整客户端到节点的传输时，查看 [HTTP/3 与智能回退](/account/http3)。保存后须更新客户端订阅；独享 IP 按地址分别设置

## 独享 IP：长期稳定的出口 {#dedicated-ip}

独享 IP 为当前账户单独分配出口地址，正常续费保留原地址。独享不等于住宅 IP，也不代表地址没有历史记录

### 有哪些实际好处？ {#ip-benefits}

| 好处 | 适用场景 |
| --- | --- |
| 固定出口 | 日常登录、远程办公和业务访问使用同一地址，便于核对访问记录 |
| 减少共享干扰 | 减少其他账户共用同一 IP 带来的异常请求、频率限制和信誉牵连 |
| 便于 IP 授权 | 为支持来源 IP 白名单的服务器或办公系统登记固定地址，减少授权变更 |

### 怎样理解 IP 信誉？ {#ip-reputation}

> 真正理想的 IP，不是让服务商知道你是一个特殊用户，而是让服务商根本没有理由觉得你是一个特殊用户

这是长期稳定、正常使用所追求的状态，并非所有平台的共同待遇。平台仍会根据 ASN（地址所属网络）、地理位置、IP 历史和使用行为独立评估；独享 IP 不保证免验证、免封禁或流媒体解锁，也不能隔离所属网络的信誉影响

## 购买与续费独享 IP

入口：登录网站 → [节点列表 → 独享 IP](https://oixcloud.com/user/node?node_level=Exclusive)（**Exclusive IP**）

| 核对项 | 要求 |
| --- | --- |
| 套餐资格 | 购买、续费和使用须有当前有效套餐；仅有待激活套餐时需先激活 |
| 独立租期 | 独立计费和计时，可以超过套餐期限 |
| 起算时间 | 新购从购买时起算；未到期续费从原到期时间延长，已到期但尚未回收时从续费时起算 |
| 购买与手动续费月数 | 单次最多 12 个月；新购还须满足商品显示的最低月数，手动续费可选 1 个月起 |
| 计费月 | 每月固定 30 天，窗口显示「本次到期时间（UTC+8）」 |

::: warning 套餐到期不会暂停 IP 租期
套餐到期后暂停使用独享 IP，地址保留至自身到期，但租期不暂停、不顺延。恢复有效套餐后，可继续使用尚未到期的 IP；已回收的地址不保证能够重新购买
:::

### 自动续费 {#ip-auto-renewal}

| 项目 | 规则 |
| --- | --- |
| 尝试时间 | IP 到期前 24 小时内 |
| 每次续期 | 延长 30 天，系统不会自动增加扣款月数 |
| 扣款条件 | 有当前有效套餐、足够的可用余额支付租金及需补足的 [保证金](#ip-deposit)，且节点正常提供服务；租金按商品当前月价计算 |
| 条件不符 | 保留开关、暂停扣款，到期前继续尝试 |

::: warning 到期前确认续费结果
展开节点卡片的 IP 列表，在对应地址旁开启「自动续费」，开启时不扣款；关闭不改变当前有效期。IP 与套餐分别续费，不为套餐续费预留余额，请分别核对余额和续费结果

IP 到期后、回收前再尝试一次自动续费，失败则回收。节点维护期间不扣费续费，页面保留地址并标注维护中；期间到期的 IP 最多保留 14 天并发送通知，节点恢复后尝试续费，未续上或满 14 天仍未恢复则回收
:::

### 保证金与滥用费用 {#ip-deposit}

部分独享 IP 商品须缴纳保证金，每个 IP 一份，用于担保该 IP 不被滥用，金额在商品列表和购买窗口显示；在商品列表点击保证金标签可查看说明

| 项目 | 规则 |
| --- | --- |
| 收取 | 新购时与租金一起扣除（一次满 6 个月的除外），购买窗口的应付合计已含保证金；余额不足时窗口会提示还需充值的金额 |
| 免收 | • **单次满 6 个月**：当次购买或续费不收保证金，已交的继续保管<br>• **累计满 12 个月**：同一 IP 累计付费满 12 个月（新购、手动和自动续费均计入）后不再需要保证金；已交保证金直接抵扣达到 12 个月时的那次续费，超出租金的部分退还至账户余额<br>续费窗口会显示累计付费月数、抵扣金额和实际应付 |
| 补足 | 保证金因经核实的滥用被扣除或商品调整后低于要求时，之后不满足免收条件的手动或自动续费一并补足，续费窗口显示需补足的金额 |
| 查看 | 节点列表的独享 IP 卡片显示当前保证金；已回收的 IP 在节点列表「Exclusive IP」页顶部显示待退还金额和预计时间 |
| 退还 | IP 停止续费、到期回收满 14 天后，未被扣除的保证金自动全额退还至账户余额，并发送通知 |
| 删除账户 | 保证金退还前不能删除账户 |

::: tip 退还的保证金只能用于消费
保证金退还至账户余额，不可提现，也不会原路退回，仅可在面板内用于购买套餐、续费等消费
:::

独享 IP 仅供本人账户使用。涉及垃圾邮件、端口扫描、攻击、版权等投诉时，须先核实持有期间的滥用行为及相关责任；仅收到投诉不构成扣款依据。核实后保证金一次性扣除，之后续费按上述规则补足；同一事件不重复扣取，已扣保证金的不再另收该事件的上游处理费。未扣保证金时，仅按有依据且实际发生的上游处理费收取一次，从余额和佣金扣除；余额因此为负时，账户可能按欠费停用，充值补足后恢复。扣款时或扣款后会及时安排通知依据及金额，有异议可提交 [服务单](/help/support) 复核并纠正误扣。完整规则以 [服务条款](https://oixcloud.com/tos#section-tos-dedicated-ip) 第 1.10 条为准

::: warning 避免产生投诉
不要通过独享 IP 群发邮件、扫描端口、进行 P2P／BitTorrent 下载或访问未经授权的系统。投诉按发生时间追溯到当时持有该 IP 的账户，保证金退还后才收到的投诉，仍可能被追加收取费用
:::

1. 在 [节点列表](https://oixcloud.com/user/node) 核对账户可用节点、地区、线路和倍率
2. 更新客户端的托管配置；节点不在列表时先查 [筛选条件](/account/subscriptions)，不要把没有显示直接当成故障
3. 选择一条符合用途的节点，先测试同一个目标网站或应用
4. 延迟正常但业务失败时，在连接记录确认流量确实经它出站，再换同地区另一节点作对照

需要特定流媒体地区时查看 [流媒体设置](/account/unlock#streaming-regions)；需要自动切换时使用客户端的策略组。每次只改一个变量，便于区分本地接管、路由、节点和目标服务的问题

## 独享 IP 购买后的检查

1. 点击商品的「购买」，选择月数，核对到期时间和应付合计；阅读租期及 [保证金规则](#ip-deposit) 后确认，提交即扣款并分配 1 个地址
2. 核对分配的地址和到期时间，在 [订阅筛选](/account/subscriptions) 预览中确认该地址被保留，再更新客户端配置
3. 选择该 IP，建立新连接，用实际业务核对出口

手动续费：展开 IP 列表 → 核对完整地址 →「续费」→ 选择月数并确认应付金额。商品停售不影响已购 IP 的使用和续费

附赠服务以同页显示的卡片为准，持有对应商品未到期的 IP 后可查看地址、账号和使用文档；凭据请勿公开分享

### 常见问题 {#ip-troubleshooting}

| 现象 | 先检查 |
| --- | --- |
| IP 未到期但不能使用 | 按上方套餐资格及到期说明检查，恢复有效套餐后更新客户端配置 |
| 付款结果不明确 | 先刷新节点列表，核对已分配地址与到期时间；不要立即重复新购 |
| 已选独享 IP，但目标看到其他出口 | 在连接记录核对命中策略，再检查 [中继](/account/relay)、[WARP 与解锁](/account/unlock) 是否改变最终出口；建立新连接重新验证 |
| 仍有验证码或访问限制 | 记录目标服务、错误、时间和实际出口，按平台提示处理，避免高频重试 |

## 支持节点的独立 IPv6 {#dedicated-ipv6}

在 [流量路由总览](https://oixcloud.com/user/route) 的「账户通用设置」里查看「独立 IPv6」及支持节点列表，按需开启。仅列出的支持节点会使用为账户分配的独立 IPv6 出口，其他节点不受影响；没有可用支持节点时不显示此设置

保存后等待节点同步，以新连接验证目标服务看到的出口。这里控制服务端节点的出口，与本机是否接管 IPv6、是否请求 AAAA 记录及连接节点使用的地址族不同，不能用客户端的一个 IPv6 开关代替核对

若希望目标网站只看到 IPv4 出口，使用 [IPv4 Only](/account/unlock#ipv4-only)；该限制在所选支持节点上优先生效，独立 IPv6 设置本身会保留

## 查看服务状态 {#service-status}

登录后打开 [服务状态](https://oixcloud.com/status)，按当前账户可见的节点范围查看状态与更新时间。页面会自动刷新，刷新失败时会提示并稍后重试；节点状态不等于从你当前网络到目标服务的连接测试

若状态正常但仍无法访问，在客户端更新配置后用同一目标做对照，并按 [故障排查](/help/troubleshooting) 提交节点名称、时间与具体错误
