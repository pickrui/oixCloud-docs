# 账户与令牌安全

在网站管理密码、Passkey 和两步验证。要查看哪些设备已登录、给脚本换令牌或关闭账户，请按对应步骤操作

- [登录客户端或让设备下线](/account/client-sign-in)
- [创建或撤销 Access Token](/account/access-tokens)
- [注销账户](/account/delete-account#delete-account)

## Telegram 绑定与每日通知 {#notifications}

1. 打开 [账户设置 → 通知与绑定](https://oixcloud.com/user/edit#settings-telegram)，Telegram 卡片标题旁显示「已绑定」或「未绑定」；未绑定时点「前往绑定」并按机器人提示完成，完成后页面会自动刷新。链接点击时生成，过期后重新点击「前往绑定」即可
2. 卡片显示「已绑定」但写着「未设置 Telegram 用户名」时仍是已绑定，无需为了补用户名重复绑定
3. 在旁边的「每日通知」卡片分别设置邮件和 Telegram 开关，等待下方状态确认；未绑定 Telegram 时，该通知开关不可用
4. 保存失败或结果未确认时，先刷新页面核对实际状态再重试；正在保存时不要重复点击

每日通知开关只控制每日通知，不能据此判断安全、支付或服务状态提醒是否关闭。解绑后，Telegram 登录、每日通知、机器人、用户群及 Telegram 内置用户中心均会停用，操作前请确认不再需要该绑定。解绑时在 Telegram 卡片点「解除绑定」，在弹窗里用 Passkey 或当前登录密码确认

## 修改密码前确认影响 {#change-password}

修改密码前，确认能够在相关设备完成以下更新：

| 受影响的凭据 | 修改密码后的处理 |
| --- | --- |
| 已登录的客户端 | 所有设备下线，需要在客户端重新登录 |
| Access Token | 全部删除，用它们的设备和脚本需要换用新增的 Token |
| Passkey | 已有记录被清除，不能继续登录网站，需要重新添加 |
| 旧主订阅地址 | 地址被删除，使用它的客户端需更新订阅地址 |

1. 打开 [账户设置 → 登录密码](https://oixcloud.com/user/edit#settings-password)，链接会直接展开修改表单（从页面进入时在「登录密码」卡片点「修改」），填写当前密码、新密码及确认密码。忘记当前密码时，点该字段下方的「忘记当前密码」，改用邮件重置
2. 确认能更新其他设备的登录信息后提交，等待成功提示
3. 按提示重新登录网站，在仍需使用的客户端重新登录；需要 Access Token 时重新新增，并更新使用旧主订阅地址的设备
4. 重新添加仍需使用的 Passkey；开启账户同步时，检查其他设备和 Apple TV 的登录结果

若禁止了客户端邮箱/密码登录，客户端改用 Google 或新增的 Access Token 登录，见 [登录限制说明](/account/access-tokens#token-only)。改密码不能替代逐项核对泄露内容，个人订阅地址等仍按下方对应表处理

## 添加和管理 Passkey {#passkey}

Passkey 用于网站登录，不是客户端 Access Token，也不是 TOTP 验证码

1. 打开 [账户设置 → 登录与安全](https://oixcloud.com/user/edit#settings-passkey)，在 Passkey 卡片点「添加」
2. 输入当前账户密码，已启用 TOTP 时再输入验证器当前生成的 6 位验证码，点击「继续」。已有 Passkey 时也可以点「使用已有 Passkey 验证」，验证通过后再点「继续」
3. 按浏览器提示使用面容、指纹或 PIN 等方式验证，等待网站提示成功，确认列表出现新记录
4. 可重命名记录，方便识别；删除前确认还有可用的登录方式，删除时要用 Passkey 或当前登录密码确认，删除后该 Passkey 不能再登录此账户

取消或超时后，从 Passkey 卡片的「添加」重新开始。已提交使用的 TOTP 码不要重复使用，等待验证器生成新码；只完成系统验证窗口而没有网站保存成功提示，不能视为注册完成。浏览器提示不支持时，使用支持 Passkey 的浏览器并确认当前是 HTTPS 页面

## 启用 TOTP 两步验证 {#totp}

启用后，使用密码登录网站时还需输入六位动态验证码；页面明确要求二次验证的敏感操作也需按提示完成。客户端登录不需要动态码。Passkey 是独立的登录方式，不是一次性密码

1. 打开 [账户设置 → 登录与安全](https://oixcloud.com/user/edit#settings-totp)，链接会直接打开设置弹窗（从页面进入时在「两步验证」卡片点「开启」）
2. 按弹窗里的步骤用验证器扫描二维码，或手动录入显示的密钥。想换一个密钥时点「重新生成」，页面刷新后会回到这个弹窗，要用新的二维码重新添加
3. 输入验证器生成的 6 位验证码，点「启用两步验证」，等待「两步验证已开启」
4. 保留可恢复验证器的安全方式；二维码和密钥能生成验证码，不要放入截图、日志或服务单

关闭时在「两步验证」卡片点「关闭」，输入验证器当前的 6 位验证码后点「继续」，再在弹窗里用 Passkey 或当前登录密码确认。验证失败时检查设备时间与所选账户，使用新生成的验证码再试；提示尝试过多时按页面要求等待。丢失验证器且无法完成验证时，通过 [服务单](/help/support) 说明情况，不要反复删除登录凭据

## 修改昵称 {#nickname}

打开 [账户设置 → 个人资料](https://oixcloud.com/user/edit#settings-nickname)，链接会直接展开「昵称」卡片的修改表单，填写新昵称并确认。昵称只能用字母和数字，最多 12 个字符，不能和别人重复

昵称一年只能自己改一次，第一次随时可以改；一年内卡片上会写明下次可以修改的日期。没有改成功（比如昵称已被使用）不占这次机会

## 修改登录邮箱

邮箱一年只能自己改一次，第一次随时可以改；一年内不能获取验证码，卡片上会写明下次可以修改的日期。没有改成功（比如验证码或密码不对）不占这次机会。确实要提前修改（比如旧邮箱已无法使用）时，通过 [服务单](/help/support) 说明情况

1. 打开 [账户设置 → 个人资料](https://oixcloud.com/user/edit#settings-email)，链接会直接展开「邮箱」卡片的修改表单；填写新邮箱并点「获取验证码」，在新邮箱一栏按回车也一样
2. 从新邮箱读取 8 位数字验证码并填写，点击「修改邮箱」或在验证码一栏按回车，在弹窗里用 Passkey 或当前登录密码确认
3. 确认页面提示修改成功。修改后当前登录会失效，用新邮箱重新登录，再核对账户中的邮箱

改邮箱的安全提醒使用变更前的联系方式，邮件提醒发往旧邮箱。如果收到的提醒不是本人操作，请立即联系支持。功能被停用时无法从这里修改

改邮箱、改密码、添加或删除 Passkey、创建和重新生成 Access Token、解绑 Telegram、关闭两步验证和删除账户时输错密码的次数一起计算，15 分钟内错满 5 次后，这些操作都要按页面提示等待后再试

## 哪些内容不能公开？

密码、Access Token、完整订阅地址、节点密码和证书私钥都应从截图和日志中隐藏。地址泄露时，先按[下表](#泄露后的对应处理)确认是个人订阅还是主订阅，再撤销相应地址

## 泄露后的对应处理

| 泄露内容 | 对应操作 |
| --- | --- |
| 某条个人订阅地址 | 到[订阅管理](https://oixcloud.com/user/sub_manage)删除泄露的地址。需要继续使用时新建地址并更新客户端。若对方可能已经下载节点配置，再重置连接参数并更新所有相关设备 |
| 主订阅地址或节点连接参数 | 在[订阅管理](https://oixcloud.com/user/sub_manage)找到「主订阅」，点「重置」并确认，立即更新所有设备的订阅或托管配置。重置会更换连接参数和主地址，个人订阅地址仍可拉取新配置，已登录设备和 Access Token 继续有效 |
| Access Token | 在令牌页重新生成或删除对应的 Access Token；重置订阅地址不能代替这一步 |
| 陌生设备登录 | 打开[新设备登录提醒](/account/client-sign-in#device-approval)中的链接，撤销对应的登录或 Access Token。若怀疑密码泄露，请[修改密码](#change-password) |
| 登录密码 | 按 [修改密码说明](#change-password) 重新登录客户端，更新 Access Token、主订阅与 Passkey；不要只换订阅 URL |
