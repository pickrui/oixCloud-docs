# UHD 权益

登录[权益中心](https://oixcloud.com/user/benefits#emby)，展开 **Emby** 卡片。先看自己是否已有 UHD 账户

## 首次兑换或关联 {#get-access}

| 你要做什么 | 在 Emby 卡片中操作 |
| --- | --- |
| 创建新 UHD 账户 | 点「立即兑换」，设置 UHD 用户名和密码，核对消耗额度与天数，再点「确认兑换」。兑换需有有效套餐，普通账户当前用 5 枚权益额度兑换 365 天 |
| 使用已有 UHD 账户 | 点「关联已有 UHD 账号」，输入 UHD 用户名、密码及已启用的 UHD 动态验证码，再点「验证并关联」。关联免费，账户须在本站团队内、未到期且未关联他人 |

成功后，卡片会显示 UHD 用户名和到期时间，可点「进入 UHD 面板」。可用额度和发放条件见[套餐权益额度](/account/benefit-credits)

## 延长已有账户 {#extend}

1. 在到期前展开 **Emby**，点「延长有效期」。核对将消耗的权益额度和新增天数，再点「确认延长」
2. 刷新卡片，核对新的到期时间。普通账户须有有效套餐和足够额度，延长后不能超过页面显示的有效期上限

UHD 账户到期后会被自动删除。开发者账户可免费兑换，到期前不能延期，等待过期账户自动删除后可重新兑换。若兑换或延期显示「正在确认」，先刷新核对结果，再按[UHD 兑换排查](/help/support#uhd-兑换显示正在确认)处理，避免重复提交
