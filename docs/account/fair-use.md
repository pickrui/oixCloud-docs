# 公平使用

## 连接数、共享与合理使用

个人套餐供本人多设备使用，不能转借、合租、共享或转售；团队用途以产品明确说明为准。连接数阈值不是可登录设备数量，大量并发连接、扫描、攻击等滥用可能触发限速或封禁。停止异常流量后观察恢复情况，持续异常请提供时间与节点信息提交服务单

## 连接数不是设备数

一个浏览器、下载器或应用可能同时建立很多连接；同一设备上的后台同步也会计入并发。是否需要减少连接，应对照账户显示的限制和客户端连接记录，不应只按已登录几台设备判断

## 出现限制时先做什么

1. 保存限制提示、发生时间和所用节点，先区分余额、套餐、并发或账户使用限制
2. 在客户端查看占用连接的应用，暂停已确认的大量下载、重复测速或异常后台任务
3. 检查是否把本机代理开放给了其他人、共享了订阅或泄露令牌；按 [账户安全](/account/security) 处理实际泄露的凭据
4. 停止原因明确的异常流量后检查新的状态；如果仍受限，提交具体提示与复现信息

不要通过轮换账户、共享凭据或反复重置参数来绕过限制。是否解除以及何时恢复取决于触发原因和服务规则，不能把所有限制都归为临时限速

使用前阅读 [服务条款](https://oixcloud.com/tos) 和网站列明的产品限制；需要多人使用时选择明确允许团队用途的方案
