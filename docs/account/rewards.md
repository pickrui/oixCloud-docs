# 奖励链接与购买赠礼

登录 [权益中心](https://oixcloud.com/user/benefits#reward-links)，找到「奖励链接」。这里可以自行领取奖励套餐，或生成一次性链接送给朋友，不消耗权益额度；可用活动、套餐、赠送条数与参与条件以页面为准

## 哪些购买获得赠礼 {#eligibility}

1. 展开活动的「参与条件」，核对「参与购买赠礼的套餐」、购买周期、每笔赠送条数、每人活动总上限，以及自动续费是否参与
2. 在活动启用期间，按 [购买步骤](/account/plans#purchase) 完成指定套餐与周期的实际付费购买；手动续费从同一购买入口办理
3. 返回「奖励链接」，查看可用赠礼、「还可生成」和「已生成」数量，再决定自用或送人

只有符合该活动规则的购买获得名额。充值到账本身不发放购买赠礼；零元订单、免费领取、升级／更换和后台补开不产生新名额。自动续费是否赠送由每个活动决定，活动启用前的购买不补发

获得的名额不要求原套餐一直有效。部分其他活动按当前有效套餐身份和活动开始前的购买记录判断资格，仍需按各活动的「参与条件」核对

## 奖励套餐与赠礼周期 {#reward-plan}

活动可能赠送固定套餐，也可能显示「与原购买相同的套餐」。跟随购买的活动按获得名额的那笔订单确定套餐，**赠礼周期单独预设**；例如买 Gold 年付赠 Gold 月付，买 Silver 年付赠 Silver 月付，不代表赠送同样一整年

后续升级原订单或切换账户当前套餐，不会改变已经获得的赠礼套餐。同一活动有多种可用赠礼时，按购买先后使用当前可用的名额，生成前核对可用赠礼和套餐时长；套餐暂不可用时，对应名额保留，其他可用赠礼仍可使用

## 自行领取 {#claim-self}

::: warning 先核对原订单的退款安排
自行领取也属于赠礼已领取；完成后，原购买订单停止自助退款，需联系人工处理。准备退原订单时，先阅读 [退款规则](#refunds)
:::

1. 在目标活动中点击「自行领取 1 份」
2. 核对奖励套餐、赠礼时长与确认提示，确定后使用一个名额
3. 打开 [套餐管理](https://oixcloud.com/user/bought) 核对结果：已有有效套餐时，奖励加入待激活列表；否则立即启用。待激活套餐按 [接续与激活规则](/account/plans#manual-activation) 使用，不会立即增加当前套餐的流量或期限

领取失败不消耗名额。网络中断或结果不明时，先核对套餐记录，再回到原活动重试；不要为了确认结果而连续领取另一份

## 生成链接送给朋友 {#share}

**每条链接只能领取一次，持有链接的人可以领取**。只发给预期的领取人，不要放进公开群聊、截图或公开文档；赠礼被领取后不能重置、删除或退回名额

1. 在目标活动选择「生成数量」，点击「生成领取链接」；可用名额不足时，以实际生成结果为准
2. 展开「我生成的链接」，核对每条链接的奖励套餐、状态与「领取截止」，复制并发送给朋友
3. 领取人打开链接，登录或注册准备接收赠礼的账户，再返回领取页面刷新，核对账户与套餐后点击「确认领取套餐」
4. 领取人在套餐管理核对生效或待激活记录；发送人可在原活动查看链接是否「已领取」

链接自生成起有效 365 天，这是领取期限，**不是奖励套餐的使用时长**；套餐时长以活动和领取页面为准。打开领取页面不等于已领取，仍须完成确认

## 重置、删除与活动结束 {#manage-links}

| 操作或状态 | 结果 |
| --- | --- |
| 重置未领取链接 | 原地址立即失效，换成新地址并重新计算领取期限；仍占用原名额，对应奖励套餐不变 |
| 删除未领取链接 | 原地址立即失效，对应名额退回；重新生成仍需符合活动条件 |
| 链接已领取 | 不能重置或删除，领取人之后删除账户也不退回名额 |
| 活动已结束 | 停止新赠礼名额和新链接，包括自行领取；已发链接仍按自身状态和期限领取，未领取链接仍可重置或删除 |

重置前先告知领取人原地址会失效；重置后重新发送新链接。奖励套餐或周期暂不可用时可能无法生成、重置或领取，以页面原因提示为准

## 原订单退款与赠礼 {#refunds}

退款前同时检查 [原订单的自助退款资格](/account/plans#refund) 和关联赠礼状态

| 赠礼状态 | 原订单退款的处理 |
| --- | --- |
| 尚未领取，含已生成的链接 | 退款会撤销该订单的赠礼名额，并作废未领取链接 |
| 已由本人或朋友领取 | 原订单停止自助退款，联系人工处理；人工退款保留领取人的赠礼套餐 |

原订单被后台删除也会撤销未领取赠礼。补绑折扣或更换套餐使原订单实付金额全部退回为零时，同样适用未领取撤销、已领取转人工的规则；仍有实付款的普通差价调整不新增赠礼

退款与领取同时发生时，以最终处理结果为准。准备退款时先告知领取人暂停领取；需要人工核查时，通过 [付款与套餐问题](/help/support#payment) 提供原购买记录、活动名称及相关提示

## 常见问题 {#troubleshooting}

| 现象 | 先检查 |
| --- | --- |
| 付费后没有新增名额 | 是否真正完成套餐购买、购买时间是否在活动启用期间、套餐与周期是否符合，以及自动续费是否参与 |
| 显示「暂不可生成」 | 每人活动总上限、可用名额、活动状态和奖励套餐是否可用，按页面原因处理 |
| 自行领取后当前流量没增加 | 在套餐管理查看是否加入待激活列表，按接续或激活规则使用 |
| 朋友打不开或无法领取 | 是否使用重置前的旧地址、是否过期或已领取，以及页面是否提示奖励暂不可用 |
| 退款入口消失或要求联系人工 | 核对原订单资格和是否已有任一份关联赠礼被领取 |
