# 流量与计费

## 流量如何扣除？

上传与下载都会计入使用量，并按实际经过节点的计费倍率折算。客户端显示的原始流量可能与账户扣除额度不同，具体以节点页面与账户流量记录为准

## 额度何时更新？

套餐流量以所选周期为单位，不按自然月自动重置。**有效期结束或流量用尽，以先发生者为准，均代表当前套餐已耗尽**；尚未到期不代表仍有可用流量，流量用尽后需要重新下单购买套餐

普通套餐流量耗尽后，系统先按设置尝试切换已购买的待激活套餐或自动续费，请先确认接续结果，避免重复购买。未接续时进入低速状态，且仍受套餐有效期限制；低速状态不代表原套餐流量已经恢复。恢复高速使用请按 [购买、续费与切换](/account/plans) 完成购买并确认新套餐生效，仅充值不会直接增加普通套餐流量

## 按量付费与低速模式

按量付费是独立的套餐计费方式，需要购买相应套餐并满足页面显示的余额门槛，流量费用先从账户余额扣除，不足部分自动使用佣金。套餐费、流量单价与使用条件以商店和用户中心为准，已结算费用与余额变化请核对账户记录；普通套餐进入低速模式不代表自动开通按量付费，恢复高速应先确认续费或切换方案

## 低速流量说明 {#low-speed}

普通套餐高速流量耗尽且未接续新套餐时，在套餐有效期内按以下档位提供低速流量。请先在 [用户中心](https://oixcloud.com/user) 确认当前生效的套餐

| 当前套餐 | 低速速率上限 |
| --- | --- |
| Pass Iron、Pass Alu、Pass Bronze | 32&nbsp;KiB/s |
| Pass Silver、Pass Gold | 128&nbsp;KiB/s |
| Pass Platinum、Pass Diamond、Pass Titanium、Developer Licenses、Team License、Enterprise Licenses | 256&nbsp;KiB/s |

`1 KiB/s = 1024 字节/秒`。这些数值是速率上限，不是保证下载速度；上下行都会受限，同一账户在同一节点服务内的多个连接共享速率，并非每台设备、每条连接各享一份。线路、协议和其他更低的限速也会影响实际速度

还需注意以下条件：

- **异常占用**：严重超量或持续异常占用资源时，服务可能进一步受限，具体以账户状态及通知为准
- **游戏加速节点**：低速状态下无法正常使用，应先恢复高速流量
- **按量付费套餐**：不适用上表；进入受限状态时，应按当前套餐要求补足资金并等待系统检查
- **并发使用**：低速状态不适合高并发任务，连接可能受到限制；请关闭不必要的并发任务
- **有效期与用途**：低速流量不限量仍受套餐有效期和服务条款约束，不代表无限速率、无限连接或允许持续异常占用资源

恢复高速时，先确认新套餐已生效且有可用流量，再等待系统与节点同步；若现有连接仍慢，断开后重新连接并验证。仅充值不会直接恢复普通套餐流量，积分回升也不会解除流量耗尽限制

## 区分几种限速与恢复条件 {#limits}

| 看到的情况 | 应核对什么 | 恢复依据 |
| --- | --- | --- |
| 高速流量耗尽后进入低速 | 当前额度、有效期、待激活队列和自动续费 | 当前有效套餐恢复可用流量后，等待系统检查；仅充值不会给普通套餐直接增加流量 |
| 按量套餐余额不足 | 账户余额、佣金和按量计费条件 | 补足资金并满足当前套餐条件后等待检查；不要只看积分 |
| 公平使用积分限速 | 积分、活动请求和 Working nodes | 正常使用后积分恢复到高于 10，再由系统解除本项限速 |
| 套餐到期或账户被限制／封禁 | 有效期、账户状态及通知 | 按实际原因续接套餐或联系支持；积分回升不等于自动恢复服务 |

几种限制可能同时存在。低速流量不限量仍受有效期、请求与节点资源限制及服务条款约束；并非不限速，也不允许持续异常使用。积分算法、自动异常检测说明与复核方式见 [公平使用](/account/fair-use)

## 用一个例子理解倍率

假设某节点倍率为 `2×`，一次连接上传 `100 MiB`、下载 `400 MiB`，折算为 `1000 MiB` 计费流量。它不是只按下载的 `400 MiB` 扣除，客户端显示的瞬时速度也不是剩余额度

这里的数字仅用于说明计算方式，实际倍率看节点页面，实际扣量看账户记录

## 查看异常用量

1. 在用户中心核对生效套餐、额度、有效期以及当前是否低速
2. 打开流量使用统计，定位用量增长的时间段，再对照当时所用节点的倍率
3. 在客户端连接记录中检查后台同步、云盘、大文件下载或重复测速；这些活动即使没有打开网页也可能持续传输
4. 暂停已确认的高流量任务后观察新的记录，不要用一次下载速度推断整段时间的计费用量

切换待激活套餐前先看 [套餐切换规则](/account/plans)，避免为了查看新额度而误激活下一期。按量付费用户另外核对余额、佣金和商品单价
