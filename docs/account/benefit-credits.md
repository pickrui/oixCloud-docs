# 权益额度与提前结束套餐 {#benefit-credits}

Pass Gold 及以上年付套餐（含按量付费）在自然到期或[提前结束并结算](#end-plan)时，按当时的套餐状态发放权益额度。开发者账户不参与

| 结算时的套餐状态 | 发放额度 |
| --- | --- |
| 普通套餐，剩余流量大于 0 且不足 50% | 5 枚 |
| 普通套餐，剩余流量至少 50% | 10 枚 |
| 普通套餐，流量已耗尽 | 不发放 |
| 符合上述条件的按量付费套餐 | 固定 5 枚 |

本期付费重置过流量、已退款或从未激活的记录不发放额度。普通套餐耗尽流量后低速使用至到期，结算仍为零。可在[权益中心](https://oixcloud.com/user/benefits)核对可用额度，也可用额度[兑换 UHD 权益](/account/uhd)

## 提前结束并结算 {#end-plan}

**确认后，当前套餐的剩余时间和流量永久作废，不退款，这份记录也退出续费队列**。已有待激活套餐时会立即启用下一份，否则代理服务停止

1. 在[套餐管理](https://oixcloud.com/user/bought)找到「使用中」记录，点「提前结束」
2. 核对弹窗里的权益额度（可能为 0）和下一份套餐或停服提示。接受后再点「提前结束并结算」
3. 回到套餐管理查看生效状态，并在权益中心核对额度
