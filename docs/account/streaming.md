1. 打开[流媒体解锁](https://oixcloud.com/user/media-unlock)，搜索节点或按「已设置」「跟随节点默认」「不可用」筛选。要清除多个节点的全部自定义地区，勾选这些节点，再批量恢复默认；只想改一个服务时用下方步骤
2. 找到该节点下需要调整的服务，从下拉框选择地区。每个服务独立设置，其他服务无需一起修改；同一逻辑节点的后端会同步使用这一选择
3. 修改后自动保存，等待下拉框下方的「已保存」提示，无需再找保存按钮。保存失败或网络超时时先刷新核对，不能仅凭下拉框显示判断服务器是否保存
4. 等待节点同步，关闭该服务的旧连接，再通过修改过的节点建立新连接，验证内容库和实际播放。仅修改地区**无需更新订阅**；若同时改了中继或 HTTP/3，按相应教程更新客户端配置

要恢复默认，在该服务的下拉框中选择「跟随节点默认」；它会清除该节点、该服务的自定义地区，不会清空其他服务，也不表示关闭所有解锁。若显示「设置不一致，请重新选择地区」，重新选择所需地区或默认值并等待保存，以统一同一节点的设置

选择某个地区不保证该服务的所有请求、内容和其他网站都从该地区出站，也不替代第三方平台的账户、会员或内容授权。普通查 IP 网站与流媒体服务可能走不同出口，应以目标服务的内容库和播放结果核验

## 与 WARP、中继和 IPv4 Only 的关系 {#streaming-routing}

- **WARP 优先**：节点开启 WARP 时，连接按 WARP 策略处理，不叠加这里保存的流媒体地区；即使 WARP 智能回退到普通出口，也不会再转入该流媒体地区设置。地区选择会保留，关闭 WARP 并等待同步后重新验证
- **内部中继先转发**：地区由最终处理目标连接的节点及其可用解锁规则决定，仅在入口保存地区不保证最后采用它。先核对[内部中继路径](/account/relay)
- **IPv4 Only 限制地址族**：它不会替你选择地区；仅有 IPv6 的目标可能失败，解锁结果也可能改变，详见[IPv4 Only](/account/unlock#ipv4-only)
- **解锁出口故障可能回退**：没有可用解锁出口或出口连接失败时，节点可能使用普通出口，地区随之改变。此页没有「地区必须保持，否则断开」的开关，不应把已保存地区视为固定地区保证

额外的解锁路径可能增加延迟或影响吞吐量。先在一个节点、一个服务上比较默认与所选地区，确认内容和播放正常后再调整其他项；目标服务暂时不能播放时，不要同时修改 WARP、中继和多个地区，以免难以判断影响来源

## YouTube 后台播放兼容 {#youtube-playback}

在 [流量路由总览](https://oixcloud.com/user/route) 的「账户通用设置」里开启「YouTube 后台播放兼容」，供有相关需求的 YouTube 会员使用。默认关闭，开启后可能有性能损耗，无此需求时保持关闭

保存后等待节点同步并重新连接，再验证后台播放。此项对当前账户的所有节点统一设置，不替代 YouTube 会员资格，也不同于流媒体地区选择
