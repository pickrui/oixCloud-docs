# 订阅与筛选

## 先选择接入方式

oixFlow、FlClash for oixCloud、集成账户入口的 OpenClash、Merlin 路由器的 oixClash 和 oixCloud Helper 可以登录账户获取托管配置。其他兼容客户端在[用户中心 → 订阅地址](https://oixcloud.com/user#subscription-details)按客户端格式复制完整的主订阅网址，再[导入客户端](/start/quick-start#import-subscription)。[订阅管理](https://oixcloud.com/user/sub_manage)用于管理各地址与筛选，列表中的「复制 Token」只复制订阅 Token

完整配置与 Provider 节点列表用途不同；Provider 需要客户端已有配置引用，不能把它当作一份完整配置直接启动。Access Token 是登录凭据，也不是订阅网址

## 网站节点列表能看到的节点，在客户端代理列表里找不到 {#missing-nodes}

1. 在 [节点列表](https://oixcloud.com/user/node) 确认当前账户能看到目标节点。网站也找不到时，先核对已激活套餐和线路权限
2. 打开**这台设备实际使用的订阅**。如果设置过筛选，在预览中搜索节点名称，核对线路、地区和名称条件。使用默认智能订阅时，在下方「空筛选与恢复默认」查看套餐的默认线路
3. 在 oixFlow（iPhone / iPad）或 FlClash for oixCloud 的「oixCloud」账户页点「刷新节点」。旧版 FlClash for oixCloud 分开显示「刷新」和「同步」时，选「同步」。普通订阅客户端则更新已导入的地址，并选中更新后的配置
4. 回到客户端节点列表搜索同一名称。仍然缺少时，记录客户端版本、订阅格式以及节点是否出现在预览中，提交服务单时隐藏完整订阅地址

普通第三方订阅可下发的线路限于 **Edge、Home ISP 和账户独享 IP**，具体节点取决于套餐权限、订阅格式和筛选。需要 CIA、IXP、Fusion 或 GIA 时，请在支持该线路的专用客户端登录。若有 IXP 权限但智能优选只显示 Fusion，可在筛选中同时保留 IXP 和仍要用的线路。自行转发的步骤见 [IXP 接入方式](/account/nodes#ixp)

1. 打开客户端「oixCloud → 节点筛选」，Helper 使用「连接设置 → 节点筛选…」；也可在网站订阅管理中编辑对应地址
2. 点线路或地区，在「不筛选 → 仅保留 → 排除」间切换；线路与地区的条件共同作用
3. 需要时填写「名称包含」或「名称排除」，等待预览完成，检查保留数量和目标节点
4. 保存后按下表检查客户端刷新结果，再重新选择可用节点并连接

| 客户端 | 保存后如何应用 |
| --- | --- |
| oixFlow | 自动刷新托管节点，检查刷新结果与当前出口 |
| FlClash for oixCloud | 自动刷新账户并同步托管配置。若同步失败，按提示处理后在账户页点「刷新节点」重试 |
| oixCloud Helper | 重新获取节点并更新映射；使用 Surge 时再次「接入 Surge」 |
| OpenClash | 网站编辑器保存后重启 OpenClash 立即获取，或等待内核下次订阅更新 |
| oixClash | 插件账号栏「订阅管理」打开网站编辑器，保存后在插件点「更新节点」立即获取，或等待每天自动更新 |
| 普通订阅客户端 | 更新所导入的那条订阅地址，并确认选中了新配置 |

名称支持不区分大小写的正则表达式，例如 `香港|日本` 表示名称含任一词；节点名不会随界面语言翻译。预览里的搜索只帮助查找，不会改变筛选条件。先等预览完成并修正无效的表达式。在官方客户端或编辑客户端专用地址时，至少要保留一个节点才能保存

图解见 [oixFlow](/oixflow/proxies#更新与筛选) 和 [FlClash for oixCloud](/flclash/profiles#托管订阅选项)

## 空筛选与恢复默认

| 地址用途 | 没有自定义条件时 |
| --- | --- |
| 官方客户端的智能订阅 | 按套餐下发智能优选的默认线路：<br>• **含 Fusion 的套餐**：有权限的 Fusion 与 GIA（不含独享 IP 和 Home ISP）<br>• **含 CIA／IXP 的套餐**：CIA + IXP（不含独享 IP 和 Home ISP）<br>• **仅含 Edge 的套餐**：Edge、允许默认下发的 Home ISP 及账户独享 IP<br>仅当上述默认集合为空时，才回退到有权限且允许默认下发的节点 |
| 普通个人订阅地址 | 返回该订阅格式下账户有权限且允许默认下发的节点，不再附加自定义筛选 |

oixFlow 对已保存的自定义筛选会先确认再恢复服务端默认；尚未保存的草稿可直接清空。FlClash for oixCloud 的「恢复默认」直接提交重置并发起同步。Helper 的「恢复默认」先清空草稿，还需点击「保存」

恢复默认不提高套餐权限，也不保证每种订阅格式都支持相同节点。旧教程中的「所有节点」「海外网络环境」「应急模式」已由可视化筛选取代

## 将 Home ISP 加入订阅 {#home-isp}

静态和动态 Home ISP 都按节点控制默认下发。含 CIA、IXP、Fusion 或 GIA 的套餐通常优选自己的线路。若默认线路没有可用节点，回退结果可能包含账户有权使用且已开启默认下发的 Home ISP。其他 Home ISP 需要手动保留 ISP 线路

1. 在当前订阅地址的节点筛选中找到线路 **ISP**，设为「仅保留」；需要其他线路时，一并将它们设为「仅保留」
2. 按需结合地区和名称筛选，等待预览完成，确认目标节点及保留数量
3. 保存并更新客户端订阅，重新选择节点连接；静态与动态家宽均属于 ISP，Edge 是另一条线路

仅按地区或名称筛选不会自动加入这类节点。恢复默认后，未默认下发的 ISP 会再次从结果中移除。中继与代理链配置步骤见 [Home ISP 使用指南](/account/home-isp)，节点的路由资格见[流量路由限制](/account/nodes#isp-routing)

## 哪些设备会一起改变？

筛选跟着**订阅地址**走。用邮箱/密码或 Google 登录的同款官方客户端共用该客户端的绑定地址。手动创建的 Access Token 使用自己的绑定。两台设备只要使用同一条地址，修改筛选后都会在下次刷新时看到变化

- 已绑定个人订阅地址时，保存或恢复默认都会改动那条地址
- 未绑定个人地址时，面板能识别的官方客户端首次保存会自动创建或复用客户端专用地址，主订阅的筛选保留
- 普通第三方工具或脚本使用未绑定的 Access Token 时，可以读取和预览。要保存或恢复默认，先到 [Access Token 管理](https://oixcloud.com/user/token)，把这个 Token 的「订阅配置」设为一条个人订阅地址

## 账号自定义规则 {#account-rules}

网站 [自定义规则](https://oixcloud.com/user/rule) 按账号共用，修改会影响实际使用这份规则的订阅或客户端；节点筛选则按订阅地址保存，可因客户端而不同

如果保存时提示策略组大小写有误，按提示的行号和组名修改。使用自有节点或特定模板的组名时，保存后还要检查目标订阅；生成 Clash 配置时，找不到对应目标的规则会跳过

oixClash 使用这份账号规则，支持的插件版本可直接读取和编辑；网站保存后，在插件点「更新节点」获取，操作步骤见 [oixClash 账号规则](/other/oixclash#_7-编辑账号自定义规则)。oixFlow App 内添加的本地分流规则仍在 App 中单独管理

清空并保存会删除账号规则，先保留需要的内容。保存成功后，还需确认客户端配置更新成功，并用新连接核对实际命中结果

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 找不到筛选入口 | 先确认账户已开通套餐并使用支持筛选的客户端。Pass Iron 也可以筛选其有权使用的节点 |
| 能预览但保存被拒绝 | 先读错误提示。若提示需要独立地址，按上方说明给当前 Token 绑定个人订阅地址 |
| 保存后仍是旧节点 | 核对设备使用的订阅地址、同步结果，以及使用同一地址的其他设备是否改过筛选 |
| 想保留独享 IP | 在预览中确认它被保留，不要把空筛选理解为官方客户端的全部节点 |
| 修改 URL 的旧地区参数无效 | 官方客户端的智能订阅使用可视化筛选；已启用筛选的普通地址也会忽略旧地区、名称和模式参数 |

精简规则、TCP Fast Open 等其他参数按客户端提供的入口调整。例如支持这些参数的订阅可使用 `&simplerules=true&tfo=false`；不要把不同客户端的格式或参数直接互换
