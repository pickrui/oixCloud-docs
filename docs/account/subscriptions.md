# 订阅与筛选

## 账户登录与订阅导入的区别

oixCloud、FlClash for oixCloud、支持账户接入的 OpenClash 和 Surge 助手可以通过账户获取配置；其他兼容客户端应在用户中心选择对应格式的订阅地址。导入成功后仍需在客户端启用配置、启动代理并选择节点

## 管理订阅与可选项

在用户中心创建或编辑订阅时，按页面提供的选项选择节点、分流规则和客户端支持的功能，再复制新地址并更新客户端。不要把 Clash、Surge 等不同格式互换，也不要套用旧文档中的查询参数；托管刷新可能覆盖直接编辑的生成内容，自定义需求优先使用界面提供的设置

## 常见订阅选项怎么选？

「所有节点」只列出当前套餐有权使用的节点，不会提升权限；「海外网络环境」用于中国大陆以外的网络；「应急模式」仅在符合条件的套餐中使用备用节点。地区、名称筛选和精简规则按页面说明选择，保存后在客户端刷新节点或同步配置

## 其他高级参数怎么填？

留空使用默认值；需要调整时用 &key=value，多项用 & 连接，例如 &simplerules=true&tfo=false，表示启用精简规则并关闭 TCP Fast Open。布尔选项使用 true / false，仅对支持该功能的客户端生效。地区、名称与节点选择请使用上方筛选器，不要在此重复填写
