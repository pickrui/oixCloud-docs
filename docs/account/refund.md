**退款会结束这份套餐，款项仅退到账户余额，不退到原支付渠道，也不是提现；已使用的折扣代码不退还**。自助入口支持符合条件、有可退实付金额且从未使用的待激活记录，不限月付、季付、半年付或年付，按该记录的实付金额全额退回；按量付费和开发者套餐不提供自助退款。曾使用后切回待激活也不符合条件

**新规则下实际获赠名额的订单不提供自助退款，尚未领取赠礼时也一样；历史订单保留原规则：符合资格的退款撤销未领取赠礼，已有赠礼被本人或朋友领取时转人工处理，已领取赠礼保留**。操作前阅读 [赠礼与退款规则](/account/rewards#refunds)

1. 在 [套餐管理](https://oixcloud.com/user/bought) 找到原记录，核对套餐名称、周期和「待激活」状态，点击「退款至余额」
2. 在「请确认」窗口核对本次退回金额与结束套餐的后果。金额按该记录的实际已付金额核算，已发生的补款或差额退款也会影响它，不按商店现价或续费价退款
3. 确认后点击「确定」，不退款则点「取消」。若提示金额或状态变化，刷新记录后重新核对
4. 完成后核对账户余额与「已退款」状态；该记录不再能激活或续费，当前正在使用的其他套餐不会因这笔待激活记录退款而结束

未显示入口时先检查套餐类型（按量付费和开发者套餐没有入口）、是否曾使用、记录状态，以及是否为新规则下已获赠名额的订单；历史订单再检查赠礼是否已领取；不要先激活来尝试获得退款资格。若操作结果不明，刷新余额与记录并保留提示，按 [付款与套餐问题](/help/support#payment) 提供资料核查，不重复提交
