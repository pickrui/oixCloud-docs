# Surge Mac 助手

## 连接步骤

1. 在 macOS 12 或更新系统安装 Surge Mac，再从本站软件中心下载 oixCloud 的 Surge 插件并解压
2. 双击「启动 oixCloud.command」，选择「常驻启动」；在菜单栏云朵图标的「账户 → 登录…」中使用 Access Token 或邮箱与密码登录
3. 在「连接设置」选择「接入 Surge」，确认 Surge 安装配置，然后开启 Surge 的系统代理并在策略组中选择节点

这里的 Surge 插件是 Mac 上运行的外部代理助手，需要与 Surge 一起运行；它不是 iPhone / iPad 上可直接安装的 .sgmodule 模块。iPhone / iPad 可使用 oixCloud。更改接入模式后重新执行「接入 Surge」；异常时先查看助手的「工具 → 诊断…」
